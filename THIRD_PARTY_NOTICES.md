# Third-party sources

This project was assembled for local use from the two supplied directories. The original Whimbox distribution and reference checkout have since been removed; required adapted code, assets and license notices remain bundled in this project.

- **ok-script** — ok-oldking, source: https://github.com/ok-oldking/ok-script ; local checkout commit `2424dc7`. The framework remains in its own directory. Its original modified Apache / Commons Clause terms are preserved verbatim in `licenses/ok-script-LICENSE.txt` and `ok-script/LICENSE.txt`.
- **Whimbox / 奇想盒 3.1.1** — nikkigallery, source identified by the supplied distribution metadata: https://github.com/nikkigallery/whimbox . The original GPL v3 license is preserved in `licenses/whimbox-GPL-3.0.txt`. The task sources were read as references for game UI flow and key defaults. Image annotations, OCR models, dictionaries and font were imported from the supplied distribution, retaining source paths and checksums in `assets/manifest.json`. The original application and its account / service configuration are not imported into the new runtime.
- **RapidOCR and PaddleOCR models** — supplied through Whimbox's bundled `rapidocr/models`; the runtime uses RapidOCR 3.4.1, ONNX Runtime and the local model files. Package metadata and bundled notices remain available in `.venv/Lib/site-packages` and `licenses/`.
- **Route and map data** — copied from the supplied Whimbox distribution into `routes/` and `assets/maps/`. `routes/manifest.json` records source and destination SHA256 and the animal-route migration. Map coordinate constants and task-card positions follow the supplied reference source; the movement adapter uses ok-script input and observed displacement, with no Whimbox runtime imports.
- **Qt for Python / PySide6, QFluentWidgets, OpenCV and other Python dependencies** — license notices are included in their installed distribution metadata. `requirements-lock.txt` records the installed versions.
- **Momo / 大喵 app icon (0.9.6)** — original character artwork from the official Infinity Nikki activity page https://infinitynikki.infoldgames.com/proj/tw/momo_search.html, asset https://assets.infoldgames.com/resources/cdn/20250717/99d73f658a1ddc81.png. Original PNG, checksum and avatar framing are recorded in `assets/branding/momo-source.json`. Papergames / Infold retain the original character artwork rights; the icon adaptation does not claim ownership or relicense that artwork under this project's software terms.

The new application uses screen capture, visual recognition and the ok-script interaction interfaces. The original framework and reference application were not modified to implement its tasks. No claim is made to ownership of third-party code, game images, models or trademarks.

Version 0.6.0 additionally references the official Whimbox repository at https://github.com/nikkigallery/Whimbox, pinned to commit `2a75df818c28e9f4af2b3e81c0db12d7694a20d1` (3.1.1, 2026-10-23). Adapted elements include daily ordering and card priorities, material tracking HSV/circle thresholds, interruption/checkpoint recovery order and eight star-crystal route anchors. The adapter uses ok-script capture/input and adds bounded retries and observed-loot reporting. Three additional UI sprites retain original source paths and hashes in the asset manifest. The removed reference checkout was not imported at runtime.

Version 0.8.0 adapts foreground input and stop/session behavior from the supplied Whimbox 3.1.1 Python sources (`interaction/interaction_core.py`, `platform/windows/input.py`, `task/task_template.py`). These remain references; the new backend implements the ok-script interaction interface without importing the Whimbox runtime. UI organization references the native Fluent task/trigger/settings registration in https://github.com/ok-oldking/ok-wuthering-waves/blob/master/config.py; no Wuthering Waves game logic or graphics were copied.

Version 0.9.0 includes original Whimbox GPL-3.0 map modules in `nuannuan/_pearpal/`: models, regional endpoints, public client, authentication and official provider. `SOURCE.json` retains pinned upstream commit and source/adapted SHA256 values. Only the logger import and public-cache directory differ; three modules are byte-identical. Original provider/authentication tests are retained with import adaptation and one region-load call-count assertion corrected for the pinned provider's two supported worlds. Qt adapters preserve upstream point coordinates, collection filtering and refresh behavior. The original GPL license remains at `licenses/whimbox-GPL-3.0.txt`.
