基于 [ok-script](https://github.com/ok-oldking/ok-script) 的《无限暖暖》Windows 桌面助手：每日任务、拾取与对话辅助、官方地图收集进度同步、可编辑路线跑图，全部在本地完成。

游戏操作流程参考 [奇想盒](https://github.com/nikkigallery/Whimbox)，界面组织参考 [ok-wuthering-waves](https://github.com/ok-oldking/ok-wuthering-waves)。

> **状态说明**：通过截图、模板匹配与本地 OCR 识别游戏界面，使用前台键鼠操作。完整每日与路线采集仍需实机验收，不能保证所有任务组合都能达到 500 分。

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11 64 位 |
| Python | 3.12（`bootstrap.ps1` 会自动使用 `py -3.12` 创建 `.venv`） |
| 其他 | Git for Windows、首次安装需联网 |
| 游戏窗口 | 16:9，至少 1280×720，推荐 1920×1080 |

识别模型、地图底图和内置路线已随源码提供，不需要另外下载奇想盒。

## 快速开始

```powershell
git clone --recurse-submodules https://github.com/drownstars/ok-nuannuan.git
cd ok-nuannuan
powershell -ExecutionPolicy Bypass -File .\bootstrap.ps1
```

安装完成后双击 **启动无限暖暖助手.vbs**，或在项目目录执行：

```powershell
.\.venv\Scripts\pythonw.exe .\start_gui.py
```

`bootstrap.ps1` 会创建项目专用 `.venv`、安装依赖并检查完整性。普通克隆未初始化子模块时会自动补齐 `ok-script`；下载源码 ZIP 时会拉取固定版本的框架（`2424dc7da0c4a16e716fade8377b69871229c479`）。

### 第一次运行

1. 登录游戏并停在大世界。
2. 在「连接」页选择 `X6Game-Win64-Shipping.exe`，运行「检查游戏画面」。捕获默认优先 WGC，黑屏时改用 BitBlt。
3. 在「游戏按键」中核对实际键位，默认为：交互 `F`、拍照 `P`、奇想日历 `L`、奇迹之旅 `J`、地图 `M`、摇铃 `X`、道具 `Z`、跳跃 `Space`。
4. 点击首页「每日任务」右侧齿轮调整计划，再点击「开始每日」。美鸭梨挖掘目标需先在游戏中设置，奇迹之旅需先完成「开启探索」。

助手运行时会恢复游戏焦点并占用键鼠；若游戏或启动器以管理员身份运行，助手也需要管理员权限。登录验证、启动器更新与系统确认由用户处理。

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `/` | 停止当前任务 |
| `F9` | 暂停 / 继续（可在基本设置中更换） |

首页与运行小窗同样有控制按钮。一次只执行一个自动任务。

## 功能一览

| 入口 | 功能 |
| --- | --- |
| 首页 / 每日任务 | 查看执行状态、设置每日计划、暂停与停止、打开运行详情 |
| 任务页 | 每日任务、独立跑图、检查游戏画面 |
| 辅助任务 | 自动拾取、对话跳过、钓鱼、动物清洁、芳间巡游、花套捕虫；默认关闭 |
| 地图遮罩 | 官方点位、地图登录与收集进度同步、本地点位导入、离线预览及游戏内显示 |
| 常用操作 | 能量检查、幻境、奇迹之冠、家园、采集与能力操作、页面跳转、进入 / 退出游戏、切换已保存账号 |
| 脚本管理 | 导入 / 播放宏与乐谱、宏录制、视觉路线录制、手动运行独立流程 |
| 路线与跑图 | 选择路线、配置能力、导入 / 编辑 / 重命名 / 删除路线、设置每日后接续跑图 |
| 设置 | 游戏键位、能量用途、材料、幻境目标、挑战次数和每日结束操作 |

自动拾取不会自动移动；对话辅助只在确认跳过标识后推进，不选择 NPC 对话选项。辅助仅在游戏前台且没有自动任务时运行。自动任务结束后保留辅助开关偏好；地图遮罩需手动重新开启。

## 每日任务

默认执行顺序：

> 进入游戏与能量检查 → 美鸭梨挖掘 → 家园 → 每周幻境 → 朝夕心愿 → 剩余能量处理 → 星光结晶 → 星海拾光 → 奇迹之冠 → 奇迹之旅奖励 → 可选接续路线 → 结束操作

家园、周本和奇迹之冠按本次界面检测结果处理；无入口或无法确认进度时跳过。每日设置集中保留朝夕心愿、星海拾光、挖掘、奇迹之旅奖励、运行模式及接续跑图等选项。

- **自动执行**：识别任务后执行已接入项目，重新读取任务卡与分数确认结果。达到 500 分后停止剩余项目，只检查已有奖励。
- **只识别**：读取所选的朝夕心愿 / 星海任务并保存结果，不领奖、不消耗日常资源、不接续跑图。
- **拍照**：仅在识别到未完成的拍照任务时触发，确认照片预览后返回。
- **奇迹之冠**：本期进度大于 0（含 23/24）即跳过挑战、领奖和兑换；仅识别到 0 进度才运行。常用操作中的手动入口不受此限制。
- **奇迹之旅**：先检查「旅行任务」和「旅行秘宝」，只有待领取奖励才领取；无奖励或状态不明时跳过。
- **结束操作**：默认保持游戏运行。可改为关闭游戏、关闭游戏和助手，并按设置关闭已验证所属的启动器；不会自动关机。

朝夕心愿已接入拍照、挖掘、采集、捕虫、战斗、幻境和小游戏等处理；星海已接入拍照、星绘图册点赞、摆饰、音乐、泡泡、动物、漂流瓶、合影及结晶路线。未接入的任务会记录原文与跳过原因。聚会聊天默认关闭；小游戏需显式允许支付噗灵。

### 活跃能量

在「扩展功能设置」选择用途，默认 **素材激化**，消耗材料默认 **布布果**。

素材激化逐份执行：确认奖励后重新读取活跃能量，**大于 100 继续，等于或低于 100 停止**。首次激化至少需要 10 点能量；读数异常、能量未下降、材料不足或奖励未确认时停止。选择祝福闪光或魔物试炼时按设置次数快速挑战，需先在游戏中解锁快速挑战；数量与消耗未确认则不继续提交。

### 每日后跑图

开启「每日结束后跑图」并选择接续路线，也可在路线页点击「每日后运行此路线」。仅在满足接续条件时执行：只识别、取消、操作失败或界面复核失败不接续；仅因不支持的任务未满分时仍可接续。每日输入前会预检所选路线及其依赖。

## 路线与脚本

内置 **24 条路线、3 个宏**。路线数据通过静态动作与传送点校验；静态校验不代表实机已可达。

跑图前确认地图与起点流转之柱已解锁。开启「跑图前自动配置能力」后，助手按路线动作配置能力方案并复核保存结果，再进行视觉定位与逐点移动。默认方案 3、漂浮跳跃，路线可覆盖默认能力。定位不可靠、持续移动无反馈或超时都会停止并释放输入。

- **导入**：支持多选 JSON 路线 / 宏，或包含 `routes`、`macros` 列表的 JSON 包；整批校验通过后写入。同名同内容复用，不同内容另存。
- **编辑**：修改名称、地图、材料目标、目标数量、点位、移动方式、动作与能力，可增删与调序。
- **删除**：删除前保留历史；仍被路线引用的宏不能删除。历史、别名与删除状态位于 `routes/.library/`。
- **宏 / 乐谱**：导入后播放，乐谱需先打开游戏演奏界面；宏循环、按键配对与等待时间均受校验。
- **录制**：宏仅采样游戏前台按键 / 鼠标，不录滚轮与完整连续鼠标轨迹；路线录制基于视觉坐标，跳跃等特殊动作需在编辑器中补充。
- **独立流程**：组合已有路线与宏，预检后按顺序手动运行（每日前后自定义流程已移除）。

路线到达终点与材料收获分别报告；采集以实际获得文本计数，零收获不会报告成功。

## 官方地图与遮罩

在「地图遮罩」选择国服 / 国际服，加载官方点位，点击「登录官方地图」，在官方页面登录后同步个人收集进度。支持隐藏已收集点位、分类筛选、手动与自动刷新、断开登录与清除登录信息。

官方数据、认证与同步复用奇想盒的地图模块，Qt 界面负责登录窗口与显示适配。助手使用独立的隔离浏览器档案，不读取其他软件保存的登录凭据。

游戏内遮罩只在游戏前台且定位可靠时显示，穿透鼠标；失焦、最小化或定位失败时隐藏。大地图需使用最大缩放档。官方点位按接口刷新，底图与定位参数不会随游戏更新自动替换；新增地图或地形变化可能需要更新底图、坐标与识别配置。操作与点位格式见 [地图遮罩说明](docs/map-overlay.md)。

## 日志与排错

| 路径 | 内容 |
| --- | --- |
| `logs/ok-script.log` | 框架运行日志 |
| `logs/startup.log` | 无控制台启动异常 |
| `logs/runs/<运行编号>/` | 本次报告、任务识别、流程事件与关键截图 |
| `logs/latest_run.json` | 首页使用的最近一次结果 |
| `configs/` | 本机设置、用户点位与隔离浏览器登录资料 |

| 现象 | 排查方向 |
| --- | --- |
| 无法启动 | 确认已完成安装，查看 `logs/startup.log` |
| 截图黑屏 | 检查游戏窗口模式，切换 WGC / BitBlt |
| 有画面但无操作 | 核对键位、前台焦点、管理员权限 |
| 任务识别失败 | 游戏更新后先运行「检查游戏画面」，识别失败会停止对应步骤 |

本机配置、登录资料、运行日志、录像、缓存、快捷方式与用户路线历史均不纳入仓库。清理时可删除旧日志与临时缓存；保留 `configs/` 以保留设置和官方地图登录状态。

## 开发与测试

```powershell
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe tools\doctor.py
```

`doctor.py` 检查依赖、本地 OCR 与游戏进程状态。`tools/smoke_gui.py` 检查实际 GUI 控件，拦截任务下发与外部操作，不发送游戏输入；会短暂打开测试窗口，结果写入 `logs/verification/`。

| 路径 | 内容 |
| --- | --- |
| `nuannuan/` | 应用源码 |
| `assets/` | 运行素材；`manifest.json` 记录来源与校验和 |
| `ok_templates/` | 模板原图与标注 |
| `routes/` | 内置路线与宏；`manifest.json` 记录来源与迁移信息 |
| `tests/`、`tools/` | 测试与开发工具；`requirements-lock.txt` 记录已验证依赖版本 |

### 源码结构

`nuannuan/` 按职责分包；新增代码请放入对应包，避免在包根目录新增模块：

| 位置 | 内容 |
| --- | --- |
| `nuannuan/config.py` | 运行路径、默认键位、ok-script 配置装配（页面与任务入口注册） |
| `nuannuan/core/` | 基础设施：`runtime.py` 画面与 OCR 适配、`interaction.py` 键鼠输入、`run_control.py` 后台任务与停止、`startup.py` 启动器、`local_app.py` 应用装配、`errors.py` 共享异常、`text.py` 数量与文本校验 |
| `nuannuan/map/` | 地图定位（`vision.py`）、点位与投影（`mask.py`）、游戏内遮罩（`overlay.py`）、地图遮罩页（`tab.py`）、素材追踪 |
| `nuannuan/routes/` | 路线数据模型（`model.py`）、路线库（`store.py`）、路线 / 能力 / 宏执行（`runtime.py`、`ability*.py`、`scripts.py`）、导航（`navigation.py`）、路线页与编辑器（`tab.py`、`editor.py`） |
| `nuannuan/daily/` | 每日与扩展日常：`runner.py` 通用游戏操作、`workflow.py` 每日入口、`extra.py` 扩展功能、目标识别与决策（`objectives.py`、`objective_*.py`）、各玩法流程（`crown.py`、`gathering.py`、`starsea_crystal.py`、`minigame.py`、`game_tools.py`） |
| `nuannuan/tasks/` | ok-script 任务入口（`daily_tasks.py`、`extra_tasks.py`）、工具分发（`tool_runner.py`）、辅助功能门控（`assist.py`） |
| `nuannuan/ui/` | Qt 页面：首页、常用操作、脚本管理、任务运行小窗与共享界面逻辑 |
| `nuannuan/pearpal/` | 官方地图数据适配、登录与面板；`_pearpal/` 为固定版本的上游 GPL 源码 |

`core/` 与 `config.py` 位于最底层，`daily/runner.py`（`DailyRunner` 通用游戏操作）与 `core/text.py` 被各层复用，`ui/`、`tasks/` 在最上层。上层可以直接导入下层；下层调用上层能力时（如 `core/runtime.py` 调用路线与任务）一律在函数内延迟导入，保证模块级导入无环。

`tools/import_assets.py`、`import_routes.py` 与 `vendor_pearpal.py` 仅用于开发时从原始来源重新导入，不是运行助手的前置步骤。`assets/feature-import.json` 保留各功能对应的上游源码路径与校验和。

测试目前覆盖任务规划、状态复核、能量处理、路线管理、输入释放、地图认证适配与本地 OCR。整套每日、新版采集、地图覆盖对齐与所有路线的实机效果仍需逐项验证。制作服装、升级祝福闪光、部分特殊星海任务、多账号一条龙与自动关机未接入。
