# 地图遮罩

官方地图的数据、认证和同步直接复用奇想盒 3.1.1 实现，固定源码与修改记录见 `nuannuan/pearpal/_pearpal/SOURCE.json`。仅替换日志和本项目缓存目录；QtWebEngine 登录窗口适配原 Electron 的隔离官方登录流程，不复制原软件账号配置。

1. 选择“国服 · 美鸭梨”或“国际服 · PearPal”，点击“加载官方点位”，也可直接开启遮罩加载。
2. 点击“登录官方地图”，在官方页面完成登录。助手只在匹配所选官方来源时读取原版使用的登录字段，交由原认证客户端核验；不会要求粘贴密码或令牌。
3. 登录后同步个人的奇想星、灵感露珠、宝箱和阅读物状态。“隐藏已收集”默认开启，可按四类分别筛选。
4. “同步收集进度”可立即刷新；地图活动与开启大地图触发原版自动刷新逻辑，周期、退避及失败处理保持原实现。
5. “断开登录”停止当前会话过滤；“清除登录信息”同时清理本助手所选区服隔离窗口的官方登录字段和 Cookie。区服、分类、隐藏设置会保存，登录状态由隔离浏览器档案保存。

公开点位坐标适配奇迹大陆与万相境；其他地图使用已有本地数据。双击官方点位可查看接口返回的说明和收集状态。点位数量会随官方数据变化，个人账号同步需在官方页登录后确认。

在“地图遮罩”页开启“显示游戏内地图点位”，切回游戏即可显示标记。窗口穿透鼠标，不点击游戏或拦截地图操作。每次启动默认关闭。

流转之柱、所选路线和手动导入点位作为补充数据保留；不替代官方点位。原应用附带的两个示例点未作为真实点位载入。

## 显示与定位

- 可分别选择流转之柱、所选路线、导入资源、大地图、小地图和名称；导入资源可按类型筛选。
- 大地图需使用左下角缩放按钮切到最大档位。拖动时暂时隐藏，稳定后根据截图重新定位。
- 小地图首次需要先打开大地图并对准角色附近，作为视觉定位的参考。无法确认位置时隐藏，提示重新定位。
- 只在游戏位于前台、窗口正常显示且地图识别可靠时绘制。切换窗口、最小化、未知页面或定位失败时隐藏。
- “预览地图”只控制助手里的离线预览；“游戏地图”控制游戏内识别，可自动识别或手动指定。离线预览支持拖动、滚轮缩放和恢复整图。
- 当前支持奇迹大陆、星海、家园和万相境，沿用项目已有地图素材。实际地图版本、客户区对齐及不同显示器上的效果尚需实机验收。

## 游戏更新后的处理

官方点位和个人收集进度通过刷新获取，不需要重新导入整个奇想盒。游戏地图底图、坐标偏移和视觉定位素材是本地资源，不会因刷新点位自动更新。

若游戏扩展了地图区域、调整地形或新增世界，需要维护对应底图及 `nuannuan/routes/model.py`、`nuannuan/map/vision.py` 中的地图配置，再验证定位和遮罩对齐。未支持的新世界不会自动获得可用的跑图路线；定位失败时遮罩隐藏，跑图停止。

## 点位文件

接受原应用的点位列表，或包含 `points` 列表的对象。`map_name` 可填 `miraland`、`starsea`、`home`、`wanxiang`。

地图图像坐标使用 `image_x` / `image_y`，单位为完整地图图像像素；游戏坐标使用 `game_x` / `game_y`，导入时自动转换。不要把预览缩略图上的屏幕坐标填入文件。

```json
{
  "points": [
    {
      "id": "my-point-001",
      "name": "自己记录的资源点",
      "label_id": "植物",
      "map_name": "starsea",
      "game_x": -35070.57,
      "game_y": 44421.60
    }
  ]
}
```

示例用于展示格式，不表示该位置存在资源。整批校验通过才保存；同 ID、同内容会复用，同 ID、不同内容会报错并保留原数据。用户点位保存在 `configs/map-points.json`。官方登录使用本助手自己的 `configs/pearpal-browser/` 隔离档案，不读取其他软件保存的凭据。
